# linkSphere

SwiftUI iOS starter created from the Xcode app template. The current UI is the default Hello World screen — not a link or networking app yet.

## Stack
- Swift / SwiftUI
- Xcode (`LinkSphere.xcodeproj`)

## Run
Open `LinkSphere.xcodeproj` in Xcode and run the `LinkSphere` scheme on a simulator or device.
